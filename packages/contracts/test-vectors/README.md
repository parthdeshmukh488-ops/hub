# Policy test vectors

`policy.json` is generated by `../scripts/generate-test-vectors.ts` and validated by `PolicyTestVectorsSchema` (`../src/test-vectors.ts`). See [../README.md](../README.md#policy-test-vectors) for the format and the rules. Every expectation is written by hand from [01-onchain-program.md §7](../../../docs/architecture/01-onchain-program.md#7-evaluation).

To add a case, edit the generator and run `pnpm --filter @leash/contracts generate`.
