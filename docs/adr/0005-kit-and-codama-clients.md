# `@solana/kit` + Codama-generated clients; no web3.js v1 in our code

- Status: Accepted
- Date: 2026-09-29
- Workstream: architecture
- Contract change: n/a (founding decision)

## Context

- `@solana/kit` is the maintained Solana JavaScript SDK (8.4.0, Sept 2026). The official Subscriptions client (`@solana/subscriptions`) is a Kit plugin, and `@x402/svm` takes Kit as a peer dependency (`>=5.1.0`).
- Codama (`codama` 1.11, `@codama/nodes-from-anchor` 1.5, `@codama/renderers-js` 2.5) generates typed Kit clients from an Anchor IDL: instruction builders, account decoders, PDA helpers, error maps.
- Mixing web3.js v1 and Kit in one codebase doubles every type (`PublicKey` vs `Address`, `Transaction` vs `TransactionMessage`) and causes subtle bugs.

## Decision

1. All our TypeScript uses `@solana/kit` types and RPC.
2. The Leash client is generated by Codama from `packages/contracts/idl/leash.json` into `packages/sdk/src/generated/`. The ergonomic layer in `packages/sdk/src/` wraps it.
3. Subscriptions interactions use `@solana/subscriptions`.
4. Program helpers come from `@solana-program/token`, `@solana-program/memo` and `@solana-program/compute-budget`.
5. Wallet connection in the web app uses a Kit-native connector. Default: `@solana/connector` (ConnectorKit, as used by the Foundation's own Subscriptions web app). WS6 may pick `@wallet-ui/react` instead, via an ADR.
6. If an unavoidable dependency requires web3.js v1, it is wrapped in one adapter file in the package that needs it, and no v1 type crosses a package boundary.

## Consequences

- Event decoding: Codama's JS renderer may not generate event decoders. WS2 then decodes Anchor events itself (8-byte discriminator + Borsh, via Kit codecs), driven by the IDL, and owns `decodeLeashEvents`.
- Solana Actions types are defined in `packages/contracts` rather than taken from `@solana/actions` (a web3.js v1 package).

## Alternatives considered

- **`@anchor-lang/core` TypeScript client:** convenient, but web3.js-flavoured and heavier. Codama gives us Kit-native types that match the Subscriptions and x402 packages.
- **gill:** a pleasant Kit wrapper, but it adds a layer the Foundation packages don't use; not needed.
